# Security policy

Hardless is a development and testing tool. By default the server binds to `127.0.0.1` only
(NFR-01) and makes no outbound network calls (NFR-04).

## Reporting a vulnerability

Please report vulnerabilities privately through
[GitHub security advisories](https://github.com/Danish-Ali097/hardless/security/advisories/new),
not in public issues. We aim to acknowledge reports within a week.

## Supported versions

Hardless has not been released yet. Once it is, security fixes go to the latest minor release.

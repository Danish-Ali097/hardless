# hardless-mcp

MCP server so AI coding agents can list devices, read rendered receipts, scan, tap and toggle faults. A thin typed layer over the REST API; stdio and Streamable HTTP.

> Status: skeleton (milestone M0). Implemented in milestone M3 (FR-43 to FR-50).

Part of [Hardless](https://github.com/Danish-Ali097/hardless), an open-source POS hardware
emulator. Licensed under Apache-2.0.

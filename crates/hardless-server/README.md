# hardless-server

The Hardless server (tokio + axum): WebSocket bridge at `/bridge`, HTTP printer endpoints, REST API at `/api/v1` and the dashboard at `/`. Owns all I/O and time for the engine.

> Status: skeleton (milestone M0). The bridge and REST API land in milestone M1 (FR-18, FR-20, FR-21).

Part of [Hardless](https://github.com/Danish-Ali097/hardless), an open-source POS hardware
emulator. Licensed under Apache-2.0.

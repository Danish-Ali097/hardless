# hardless-render

Receipt renderer: command AST to HTML, SVG and PNG at 58 mm or 80 mm, plus plain-text extraction for test assertions. Sans-IO.

> Status: skeleton (milestone M0). HTML and `to_text` land in milestone M1 (FR-10, FR-12, FR-13); SVG and PNG in M2 (FR-11).

Part of [Hardless](https://github.com/Danish-Ali097/hardless), an open-source POS hardware
emulator. Licensed under Apache-2.0.

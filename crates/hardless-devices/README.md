# hardless-devices

Emulated POS devices built on `hardless-core`: ESC/POS receipt printer, cash drawer, keyboard-wedge scanner and NFC reader, one Cargo feature per device. Sans-IO.

> Status: skeleton (milestone M0). The printer and drawer land in milestone M1 (FR-36 to FR-39).

Part of [Hardless](https://github.com/Danish-Ali097/hardless), an open-source POS hardware
emulator. Licensed under Apache-2.0.
